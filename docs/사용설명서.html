SLU Studio 사용설명서

Windows x64 · 1.12.0

1.12.0은 패널과 대화상자를 따뜻한 다크톤으로 정리했습니다. 상단 왼쪽의 SLU Studio 이름 옆에서 실행 중인 버전을 확인할 수 있습니다.

실행과 가져오기

SLU-Studio-Setup-1.12.0-x64.exe는 설치형입니다. SLU-Studio-1.12.0-Windows-x64.exe는 포터블입니다. 포터블은 실행할 때 내부 파일을 풀기 때문에 시작 시간이 더 걸립니다.

미디어 가져오기 또는 탐색기에서 파일 드래그로 영상·오디오·이미지를 엽니다. 파일 정보가 표시된 후 썸네일과 파형이 배경에서 생성됩니다. 코덱 때문에 미리보기가 나오지 않으면 해당 미디어의 프록시를 생성하세요. 출력은 연결된 원본·보정·역재생·배경 제거 결과 영상을 사용합니다.

투명 VP8·VP9 영상과 배경 제거 결과는 아래 트랙이나 프로젝트 배경과 합성합니다. FFV1 투명 영상의 미리보기용 WebM은 자동으로 생성하며 일반 프록시 설정이 꺼져 있어도 사용합니다. 투명 프록시는 CPU로 생성하므로 처리 시간과 추가 저장 공간이 필요합니다. MP4 출력은 배경까지 합친 불투명 영상입니다.

프로젝트를 열 때 앱이 만든 이전 버전 프록시 중 색상·투명도·프레임 시각이 맞지 않을 수 있는 파일의 연결을 갱신합니다. FFV1의 필수 프록시는 자동으로 준비하고, 일반 영상은 필요할 때 프록시를 다시 생성하세요. 썸네일도 갱신하며 클립 편집과 미디어 이름을 보존합니다.

소스 구간과 타임라인

  1. 미디어를 선택하면 소스 모니터에서 원본을 재생합니다. I로 시작, O로 끝을 지정합니다.
  2. 삽입은 플레이헤드 위치에 넣고 같은 트랙의 뒤 클립을 밀어냅니다. 덮어쓰기는 해당 구간의 기존 클립을 잘라 대체합니다. 끝에 추가는 트랙 끝에 놓습니다.
  3. 클립을 드래그해 이동하고 양 끝을 드래그해 길이를 조절합니다. S로 플레이헤드에서 분할합니다.
  4. Shift+클릭 또는 빈 영역 드래그로 다중 선택합니다. 오른쪽 클릭 메뉴에서도 분할·복제·삭제를 실행할 수 있습니다.
  5. 자석 스냅은 클립 경계·마커·플레이헤드에 맞춥니다. 드래그 중 Alt를 누르면 스냅을 잠시 끕니다. 이동·트리밍은 프로젝트 프레임에 맞춥니다.

트랙의 잠금, 숨김, 음소거, 단독 재생은 독립적입니다. 영상 트랙 단독 재생은 영상과 해당 오디오에, 오디오 트랙 단독 재생은 소리에 영향을 줍니다. 숨김은 소리를 끄지 않습니다. 트랙 헤더에서 이름·높이를 바꾸거나 삭제할 수 있습니다.

타임라인 위 경계선을 드래그해 패널 높이를 조절합니다. M은 마커를 추가합니다. Ctrl+마우스 휠은 포인터 위치를 기준으로 확대합니다. 긴 프로젝트는 화면에 보이는 클립과 눈금만 그립니다.

일정 속도와 속도 커브

영상·오디오 클립을 선택하고 속성의 속도 탭을 엽니다. 커브를 선택하거나 몽타주·히어로·점프·점차 가속·점차 감속 프리셋을 적용하세요. 제어점 사이의 속도는 선형으로 변하며, 원본 재생 시각은 그 속도를 누적해 계산합니다.

  • 점을 드래그해 위치와 속도를 조절합니다. 빈 곳을 두 번 클릭하거나 +로 점을 추가합니다. 화면에서 최대 32점을 편집하며, 시작·끝 점은 삭제할 수 없습니다.
  • 제어점 위치(클립의 %)와 제어점 속도(0.1–16배)를 숫자로 입력할 수 있습니다. 세로 범위 4×·8×·16×는 그래프 표시만 바꿉니다.
  • 선택 제어점으로 이동으로 해당 장면을 확인합니다. 일정 또는 커브 해제로 기존 일정 속도로 돌아갑니다. 기본 탭의 재생 속도를 입력해도 커브가 해제됩니다.

속도를 바꾸면 원본 시작·끝은 유지되고 타임라인 길이 = 원본 구간 ÷ 평균 속도가 됩니다. 예를 들어 원본 12초에 0.5→2배 가속을 적용하면 평균 1.25배, 타임라인 9.6초입니다. 키프레임·페이드 시간도 비례 조정되지만 이웃 클립과 별도 자막은 자동으로 이동하지 않으므로 겹침·간격을 확인하세요. 분할·트리밍은 남은 구간의 속도와 원본 시각 연결을 유지합니다. 슬로 모션은 기존 프레임을 사용하며 광학 흐름으로 새 프레임을 만들지 않습니다.

역재생

  1. 영상 또는 오디오 클립을 선택하고 사용할 구간을 자릅니다.
  2. 속성의 미디어 → 역재생을 누릅니다. 작업 패널에서 진행 상황을 확인하거나 취소할 수 있습니다.
  3. 완료되면 선택 구간의 영상과 소리가 뒤집힙니다. 위치·길이·속도 커브·효과는 유지합니다.

별도 결과 파일을 만들고 영상의 프레임 표시 간격과 음성 샘플을 역순으로 처리합니다. 음성 채널의 좌우 순서는 유지합니다. 클립에 속도 커브가 있으면 역재생된 원본 구간에 그 커브를 적용합니다. 역재생 해제는 이후 자른 구간까지 반영해 원본으로 되돌립니다. 적용·해제는 각각 한 번에 실행 취소할 수 있습니다.

보정한 클립을 역재생하면 기존 보정 상태를 기억합니다. 역재생 후 추가로 흔들림 보정을 한 경우 역재생·이후 보정 해제는 두 작업을 해제하고 역재생 전의 보정 상태로 돌아갑니다. 처리 중 구간을 바꾸거나 트랙을 잠그면 완성된 파일은 보관함에만 추가됩니다. 작업 결과는 시작한 프로젝트가 계속 열려 있을 때 적용합니다.

8비트 SDR 불투명 영상과 오디오, 배경 제거로 만든 FFV1 투명 영상을 지원합니다. 투명 영상은 CPU로 역재생하고 FFV1·PCM MOV로 저장하며 미리보기가 준비된 뒤 적용합니다. 투명 VP8·VP9 WebM과 HDR·고비트 영상은 역재생 지원 범위에 포함되지 않습니다. 지원되는 NVIDIA GPU에서는 불투명 H.264·HEVC·VP9·AV1의 프레임 분석과 디코딩·역순 처리를 가속합니다. 해상도·픽셀 형식·회전 등 조건에 따라 CPU로 처리하며, GPU 처리 실패 시 CPU 경로로 다시 시도합니다.

불투명 역재생 영상은 H.264와 PCM 오디오를 담은 MOV이며 영상은 손실 압축입니다. 오디오만 있으면 WAV로 저장하고, 여러 오디오 스트림이 있으면 MOV로 보관합니다. 임시 파일과 완성 파일의 저장 공간이 필요합니다. 완성 파일은 사용자 데이터 폴더/media-derived에 있으므로 프로젝트 및 원본과 함께 보관하세요.

정지 프레임 삽입

  1. 영상 트랙의 클립을 선택하고 멈출 장면으로 재생헤드를 이동합니다.
  2. 속성의 미디어 → 정지 프레임 삽입을 엽니다.
  3. 정지 길이를 입력하고 삽입을 누릅니다. 기본 3초이며 최소 한 프레임부터 1시간까지입니다. 프로젝트의 최소 클립 길이는 0.01초이므로 120fps에서는 두 프레임 이상입니다.

프록시 대신 원본에서 PNG를 만들고 선택한 트랙에 삽입합니다. 그 트랙의 뒤 클립은 정지 길이만큼 밀리며, 다른 트랙의 오디오·자막·영상은 현재 위치를 유지합니다. 정지 구간에는 원본 소리가 없습니다. 전체 편집의 동기를 유지하려면 다른 트랙도 조정하세요.

해당 시점의 크기·위치·회전·불투명도·페이드와 적용된 색상·크롭·마스크를 유지합니다. 정지 구간에서는 키프레임과 등장 애니메이션이 진행되지 않습니다. 삽입과 미디어 추가는 한 번에 실행 취소할 수 있습니다. 잠긴 트랙·전환 구간·한 프레임보다 짧은 조각이 생기는 위치에는 삽입하지 않습니다.

SDR 영상과 투명 VP9 WebM을 지원하며, HDR·광색역은 지원하지 않습니다. 회전과 픽셀 종횡비를 반영한 PNG는 최대 한 변 8192픽셀·3,500만 화소입니다. 파일은 사용자 데이터 폴더/media-derived에 저장되므로 프로젝트와 함께 보관하세요. 처리 도중 클립을 바꾸거나 잠그면 완성된 이미지는 보관함에만 추가됩니다. 다른 프로젝트를 열면 적용하지 않습니다.

흔들림 보정

  1. 영상 클립을 선택하고 속성 아래 미디어 → 흔들림 보정을 엽니다.
  2. 부드러움(0–120프레임), 분석 정밀도, 가장자리 처리, 추가 확대를 정합니다. 자동 확대는 흔들림으로 드러나는 가장자리를 잘라냅니다. 여백을 선택하면 불투명 영상은 검정, 투명 영상은 투명 여백을 만듭니다.
  3. 분석 후 적용을 누릅니다. 작업 패널에서 진행 상태를 보거나 취소할 수 있습니다.

선택 클립이 사용하는 원본 구간을 CPU로 분석하고 별도 보정 영상을 만듭니다. 적용 후에도 클립 길이·속도 커브·효과를 유지합니다. 보정 해제는 이후 트리밍한 위치까지 반영해 원본으로 되돌립니다. 다시 보정할 때도 원본에서 처리합니다. 처리 중 클립 구간을 바꾸거나 트랙을 잠그면 결과는 보관함에만 추가됩니다.

8비트 SDR의 불투명 영상과 투명 영상을 지원합니다. 불투명 영상은 H.264 CRF16·PCM MOV, 투명 영상은 FFV1·PCM MOV로 저장합니다. 투명 영상은 미리보기까지 준비한 뒤 적용하며 표시 크기 한 변 8192픽셀·3,500만 화소까지 처리합니다. HDR·고비트 입력은 지원 범위에 포함되지 않습니다. 보정 파일은 사용자 데이터 폴더/media-derived에 저장되며 파일이 커질 수 있으므로 원본과 함께 보관하세요.

인물 배경 제거

  1. 영상 클립을 선택하고 사용할 구간을 자른 뒤 속성의 미디어 → 인물 배경 제거를 엽니다.
  2. 처리 품질에서 기본 · 상반신, 기본 · 전신, ResNet50 · 전신 중 하나를 선택하고 처리 장치를 정합니다. 화면에 표시된 시작·끝은 원본 영상의 시간입니다.
  3. 배경 제거를 누릅니다. 작업 패널에서 진행 상황을 확인하거나 취소할 수 있습니다. 투명 영상과 미리보기 파일이 모두 준비되면 선택 클립에 적용합니다.
  4. 아래 트랙에 배경 영상·이미지를 놓거나 프로젝트 배경색을 바꾸고 머리카락·손·빠르게 움직이는 부분의 가장자리를 확인합니다.

빠르게 움직이는 손·팔이 일부 지워지거나 가장자리에 배경색이 남을 수 있습니다. 머리카락 사이·팔다리 틈·인물 뒤의 물체가 배경 제거 결과에 남는 경우도 있습니다. ResNet50은 일부 모발 경계를 개선했지만, 검사한 다른 장면에서는 기본 모델보다 난간이나 팔 주변 배경을 더 남겼습니다. 짧은 구간으로 모델을 비교하고 밝고 어두운 배경에서 결과를 확인하세요.

앱에 포함된 RVM 인물 모델을 이 PC에서 실행합니다. 기본 두 설정은 MobileNetV3, ResNet50 설정은 더 큰 모델을 사용합니다. 상반신의 내부 분석 크기는 긴 변 512픽셀, 전신과 ResNet50은 768픽셀이며 출력은 원본 표시 크기를 유지합니다. 자동 · GPU 우선은 DirectML을 사용하고 실행에 실패하면 같은 모델의 CPU 경로로 이어서 처리합니다. GPU를 직접 선택하면 GPU 오류를 표시하며, CPU는 처음부터 CPU로 처리합니다.

결과는 투명 FFV1 MOV와 오디오로 보관하고 별도의 WebM 미리보기를 만듭니다. 미리보기는 CPU로 생성하므로 GPU 분석이 끝난 뒤에도 준비 시간이 필요합니다. 긴 4K 영상은 처리 시간과 저장 공간을 많이 사용합니다. 결과 파일은 사용자 데이터 폴더/media-derived에 있으므로 다른 PC로 옮길 때 프로젝트 모아 저장을 사용하세요.

배경 제거 해제는 분할·트리밍한 구간을 반영해 배경 제거 전 영상으로 돌아갑니다. 이후 역재생이나 흔들림 보정을 추가했다면 배경 제거·이후 처리 해제로 함께 해제합니다. 배경 제거 전에 적용했던 원본 처리는 복원됩니다. 적용·해제는 실행 취소할 수 있습니다.

처리 중에도 위치·크기 등 편집을 할 수 있습니다. 구간 변경·클립 삭제·트랙 잠금이 생기면 결과는 보관함에 추가합니다. 작업 결과는 시작한 프로젝트가 계속 열려 있고 해당 원본 구간이 유효할 때 클립에 적용합니다. 처리 중 원본 파일 자체가 바뀌면 오류를 표시합니다.

표시 크기 한 변 4096픽셀까지의 8비트 SDR 인물 영상을 처리합니다. HDR, 이미 투명한 영상의 추가 배경 제거, 일반 사물 분리와 브러시로 윤곽을 고치는 기능은 지원 범위에 포함되지 않습니다.

위치·크기·속도·효과와 타임라인 길이를 유지합니다. 화질 향상 해제로 원본 구간을 복원할 수 있으며 적용·해제는 실행 취소할 수 있습니다. 처리 도중 구간을 바꾸거나 트랙을 잠그면 결과는 보관함에 추가합니다. 원본 파일이 바뀌면 처리를 중단합니다. 다른 PC로 옮길 때는 프로젝트 모아 저장을 사용하세요.

객체 추적

  1. 영상 클립을 선택하고 속성의 객체 추적 → 대상 지정을 엽니다. 시작·끝은 타임라인 시간이 아닌 원본 영상의 초 단위입니다.
  2. 대상이 잘 보이는 프레임에서 상자를 그립니다. 상자 안을 드래그하면 이동하고 모서리를 드래그하면 크기가 바뀝니다. Shift를 누른 채 그리면 기존 상자 안에서도 새 영역을 지정합니다.
  3. 분석 구간과 해상도·처리 장치를 정한 뒤 앞·뒤 방향 분석을 누릅니다. 기준 프레임 앞뒤를 모두 분석합니다. 시작 부분만 지정할 필요는 없습니다.
  4. 재생하거나 이전·다음 프레임으로 결과를 확인합니다. 가림·회전 등으로 상자가 벗어나면 해당 프레임에서 다시 지정하고 다시 분석을 누릅니다. 기준점은 최대 64개이며 목록에서 이동·삭제할 수 있습니다.
  5. 새 텍스트 또는 기존 텍스트·이미지를 고르고 움직임 연결을 누릅니다. 크기도 따라가기를 켜면 대상 크기 변화도 반영합니다. 연결 후에도 텍스트 스타일, 기본 위치·크기와 키프레임을 편집할 수 있습니다.

연결된 클립의 경로 검토·수정으로 다시 분석하고 수정 적용할 수 있습니다. 현재 위치에서 연결 해제는 현재 화면의 위치·크기를 유지하며 움직임 연결을 제거합니다. 기본 위치로 해제는 추적에 의한 변형을 제거합니다. 연결·수정·해제는 실행 취소할 수 있습니다. 원본 클립의 분할·트리밍·속도와 화면 변형을 따라가며, 추적 구간 밖이나 원본 조각 사이의 빈 구간에서는 가까운 유효 위치를 유지합니다.

앱에 포함된 AI 모델을 로컬에서 실행합니다. 별도 계정이나 업로드가 필요하지 않습니다. 자동 · GPU 우선은 DirectML을 사용하고 사용할 수 없으면 CPU로 처리합니다. GPU를 직접 선택했는데 실행할 수 없으면 오류를 표시합니다. 지원 여부와 속도는 GPU·드라이버·영상에 따라 달라집니다. 분석 해상도를 낮추면 작은 대상의 정확도가 떨어질 수 있습니다. 분석 중 원본 프레임을 임시 디스크에 보관하므로 저장 공간이 필요합니다.

추적은 대상의 위치·크기를 추정합니다. 물체 윤곽 추출, 배경 제거, 회전·원근 추적은 지원하지 않습니다. 가려지거나 화면 밖으로 나간 대상을 자동으로 정확하게 다시 찾는다고 보장하지 않습니다. 경로 확인 필요·대상 확인 필요 표시와 실제 결과를 확인하고 기준점을 보완하세요. 추적 결과는 .slutrack 파일이므로 아래 저장 방법에 따라 함께 보관하세요.

컷 사이 전환

  1. 같은 영상 트랙에서 맞닿은 두 영상·이미지 클립을 선택하고 보관함의 전환에서 디졸브·와이프·밀어내기·줌을 고릅니다. 컷 위의 +로도 추가할 수 있습니다.
  2. 컷에 표시된 전환을 선택해 길이(프로젝트 프레임), 진행 방식, 방향, 오디오 크로스페이드를 바꿉니다. 와이프·밀어내기는 네 방향을 지원합니다.
  3. 전환을 선택한 상태에서 Delete 또는 전환 삭제로 제거합니다. 실행 취소로 복원할 수 있습니다.

전환은 컷의 앞뒤에 걸쳐 원본의 남는 구간을 사용합니다. 클립의 시작·끝, 전체 프로젝트 길이, 기존 페이드·속도 커브는 바뀌지 않습니다. 예를 들어 30fps의 31프레임 전환은 컷 앞 15프레임과 뒤 16프레임을 사용합니다. 원본 여유 구간이 없거나 다른 클립·전환과 겹치면 길이가 제한되며, 넣을 수 없는 경우 이유를 표시합니다. 파일에 영상 길이 정보가 불명확하면 실제 프레임 범위를 먼저 분석합니다. 작업 패널에서 취소할 수 있습니다.

오디오 선형은 두 소리를 일정 비율로 교차하며, 이퀄 파워는 서로 다른 소리 사이의 음량 감소를 줄입니다. 같은 소리가 겹치면 더 크게 들릴 수 있습니다. 없음은 기존 컷 위치에서 소리가 바뀝니다. 클립 볼륨·페이드는 그대로 적용됩니다.

두 클립을 함께 복사·복제하면 전환도 따라갑니다. 프로젝트 프레임률을 바꾸면 전환 시간을 가장 가까운 새 프레임으로 유지합니다. 클립을 따로 이동·트리밍해 컷이 끊기거나 원본 여유가 부족해지면 해당 전환을 해제하고 알립니다. 실행 취소로 편집과 전환을 함께 복원합니다.

화면 효과와 키프레임

속성에서 위치·크기·회전·반전·불투명도·화면 맞춤·밝기·대비·채도·블러를 조절합니다. 위치 0, 0은 캔버스 중앙입니다. 숫자는 입력한 뒤 Enter 또는 다른 필드 클릭으로 적용합니다.

기능조작
자르기원본의 왼쪽·위·오른쪽·아래 제거 비율을 지정합니다.

분할·트리밍 후에도 기존 키프레임 곡선과 페이드 진행 위치를 유지합니다. 텍스트는 영상 위에 합성됩니다. 같은 트랙에서는 나중에 시작한 클립이 위에 표시됩니다.

키프레임 영역에서 위치 X·Y, 크기, 회전, 불투명도 중 하나를 선택합니다. 그래프의 점을 좌우로 움직여 시각을, 위아래로 움직여 선택한 값을 조절합니다. 아래 목록에서 이전·다음 점을 선택하고 추가·삭제와 보간 방식을 정할 수 있습니다. 한 번의 드래그는 한 번의 실행 취소로 되돌립니다.

색상별 HSL·곡선·LUT

색상별 HSL에서 빨강·노랑·초록·청록·파랑·자홍 중 하나를 선택하고 색조·채도·밝기 세 슬라이더를 조절합니다. 색조는 ±60, 채도와 밝기는 ±100 범위입니다. 초기화로 변경값을 지울 수 있습니다.

영상 또는 이미지 클립을 선택하고 속성의 색상 탭에서 곡선 · LUT를 조절합니다. 기본 밝기·대비·채도·프리셋 다음에 HSL, 곡선, LUT 순서로 적용합니다. 같은 영상의 다른 클립에는 별도로 설정할 수 있습니다.

  1. RGB(전체) 또는 빨강·초록·파랑 채널을 선택합니다. 그래프의 가로축은 입력 밝기, 세로축은 출력 밝기이며 숫자는 0–255입니다. 점을 추가하거나 드래그하고 입력·출력 숫자로 정밀하게 조절합니다. 한 채널에 최대 16점이며 양 끝 점은 삭제할 수 없습니다.
  2. LUT 가져오기로 3D .cube 파일을 선택합니다. 선택 목록에서 LUT를 바꾸고 강도를 조절합니다. LUT 강도 0은 LUT만 해제하며 곡선은 유지합니다.
  3. 색 보정의 켜기/끄기로 적용 전후를 비교합니다. 초기화는 해당 클립의 곡선과 LUT 설정을 되돌립니다. 다중 선택 시 잠기지 않은 영상·이미지에 적용합니다.

LUT는 프로젝트 안에 저장되므로 원래 .cube 파일을 옮겨도 유지됩니다. 미사용 LUT 정리로 프로젝트 크기를 줄일 수 있습니다. 2–65 크기의 3D LUT만 지원하며 1D LUT·Log/HDR 자동 변환은 지원하지 않습니다. 파일 하나는 최대 16MiB, 프로젝트에는 최대 32개·총 200만 숫자까지입니다. 65³ LUT 하나는 프로젝트에서 약 4.2MiB입니다. 색 보정은 현재 8비트 SDR 결과를 기준으로 합니다.

색상 분석 패널

프로그램 모니터의 스코프 버튼을 누릅니다. 히스토그램은 밝기와 RGB 분포, 파형은 화면 가로 위치별 밝기, RGB 퍼레이드는 채널별 밝기, 벡터스코프는 색차 분포를 보여줍니다. 벡터스코프의 표시는 75% 색 막대 기준입니다. 히스토그램의 로그 표시는 낮은 빈도의 값도 확인할 때 사용합니다.

효과·전환·자막을 합성한 현재 프로그램 화면을 최대 320×180으로 줄여 초당 최대 8회 분석합니다. 정지 상태에서도 탐색·색 보정 후 갱신합니다. 표시한 시간과 밝기 최솟값·최댓값을 함께 확인하세요. 패널을 닫거나 소스 모니터로 전환하면 분석을 중지합니다. 이 패널은 SDR 편집용 저해상도 표본이며 전체 해상도 신호 분석이나 HDR 검수용 계측기는 아닙니다.

오디오 보정과 레벨

소리가 있는 영상·오디오 클립을 선택하고 속성의 오디오 → 이퀄라이저를 엽니다. EQ는 클립의 볼륨·페이드보다 먼저 적용합니다. 음성 인식이나 AI 잡음 제거 기능은 아닙니다.

  1. 밴드 1–6 중 하나를 선택하고 사용 여부와 종류를 정합니다. 저역/고역 차단은 해당 범위를 줄이고, 선반은 저음/고음을 넓게 조절하며, 피크는 특정 주파수 주변을 조절합니다.
  2. 그래프의 점을 좌우로 움직여 주파수를, 위아래로 움직여 게인을 바꿉니다. 차단 필터는 주파수만 드래그합니다. 숫자 입력으로 20–20,000 Hz, 게인 ±18 dB, Q 0.1–10을 지정할 수 있습니다. Q가 클수록 좁은 범위에 작용합니다. 선반의 기울기는 S=1로 고정됩니다.
  3. 점에 키보드 초점을 두고 좌우 화살표로 주파수, 위아래로 게인을 바꿉니다. Home/End는 주파수의 최솟값/최댓값입니다. 한 번의 드래그는 한 번의 실행 취소로 되돌립니다.
  4. EQ 체크를 끄면 설정을 보존한 채 원음과 비교합니다. 출력 게인은 보정 후 음량을 조절합니다. 평탄·보컬 명료도·저음 강조·고음 완화 프리셋은 시작점으로 사용할 수 있습니다. 초기화는 해당 클립의 EQ 설정을 지웁니다.

다중 선택에서는 잠기지 않은 소리 있는 클립에 적용합니다. 밴드 하나를 수정할 때 다른 밴드는 유지됩니다. 같은 원본·EQ·볼륨·페이드가 이어지는 단순 분할은 오디오를 연속 처리하므로 컷에서 EQ가 다시 시작하지 않습니다. 영상 효과와 클립 선택은 독립적입니다. 한쪽 EQ를 바꾸거나 전환을 넣으면 별도 처리합니다. 탐색 직후에는 필터가 새 위치에 맞춰 안정될 시간이 필요할 수 있습니다. 그래프는 48 kHz 기준이며 표시 범위 밖의 응답은 그래프 가장자리로 표시합니다.

프로그램 모니터의 오디오 레벨 버튼으로 미터를 엽니다. L/R 막대는 샘플 피크와 RMS, 흰 표시는 잠시 유지되는 피크, 아래 숫자는 마지막 초기화 이후 최대값입니다. 리미터 이전/이후를 선택해 비교합니다. 최대값이나 초기화 버튼을 누르면 기록을 지웁니다. 0 dBFS를 초과하면 빨간 표시가 남으므로 클립 볼륨이나 EQ 출력 게인을 조절하세요.

미리보기 소리를 꺼도 미터는 믹스 레벨을 표시합니다. 패널을 닫거나 소스 모니터로 전환하면 계측을 중지합니다. 이 미터는 LUFS·트루 피크·최종 파일 측정기가 아니며, 미리보기 리미터와 출력 리미터의 동작은 다릅니다.

텍스트와 자동 자막

텍스트 보관함의 자막 스타일에서 외곽선 강조·줄 배경·간결한 자막을 고릅니다. 삽입은 플레이헤드에 새 텍스트를 만들고, 선택에 적용은 선택한 잠기지 않은 자막의 모양을 바꿉니다. 문구·위치·길이·단어 시간은 유지합니다. 기존 기본 텍스트도 그대로 사용할 수 있습니다.

속성에서 굵기·색·외곽선·배경·모서리·여백·줄 간격·자간·최대 너비와 등장·퇴장 효과를 조절합니다. 선택한 Noto Sans KR 또는 Gmarket Sans로 자막을 표시하며 이모지는 포함된 Noto Color Emoji로 표시합니다. 지원하지 않는 글자는 알림으로 표시하며 해당 글자를 포함한 출력은 중단합니다. 스타일 이름을 입력해 최대 24개까지 저장할 수 있습니다. 저장 스타일을 수정하거나 삭제해도 이미 적용한 프로젝트 자막은 바뀌지 않습니다.

  1. 음성이 있는 클립을 선택하고 자동 자막을 엽니다.
  2. Base(148 MB), Small(488 MB), Large-v3-turbo Q5(574 MB) 중 모델을 설치합니다.
  3. NVIDIA GPU를 쓰려면 CUDA 음성 엔진(다운로드 약 439 MB)을 설치합니다. 자동 모드는 CUDA 실행 실패 시 CPU로 재시도합니다.
  4. 언어, 자막당 최대 글자와 시간을 지정합니다. 선택 클립의 원본 구간을 인식하고 배속·시작 위치를 반영합니다.
  5. 생성된 문구와 시간을 확인하고 수정합니다. 인식된 단어 시간이 있으면 단어 강조에 사용합니다. 문장 전체 시간만 반환된 경우에는 단어 시간이 없을 수 있습니다.

설치 이후 Whisper 음성 인식은 오프라인에서 실행합니다. 음성 파일을 서버에 업로드하지 않습니다. 긴 음성은 구간을 나눠 처리합니다. 배경음악·겹친 목소리·무음에서는 오인식이 생길 수 있으며, 음성 인식의 단어 시간도 정확성을 확인해야 합니다.

단어 시간과 강조

  1. 자막 목록에서 자막을 선택합니다. 단어 시간의 단어를 누르면 해당 위치로 이동합니다.
  2. 단어 시작·끝을 입력하거나 플레이헤드를 옮겨 현재 위치를 시작·끝으로 지정합니다. 표시 시간은 선택 자막 안에서의 시간입니다. 앞뒤 단어의 시간과 겹칠 수 없습니다.
  3. 속성의 단어 강조와 강조 색상을 조절합니다. 말하지 않는 간격에는 기본 글자 색을 사용합니다.
  4. SRT/VTT 등 단어 시간이 없는 자막은 단어 시간 균등 배치 · 추정으로 편집용 시간을 만들 수 있습니다. 음성 인식 결과가 아니며, 강조하려면 추정 시간 사용을 따로 켜야 합니다. 직접 고친 단어 시간은 직접 지정으로 표시합니다.

분할·트리밍은 남은 단어 시간과 기존 효과의 진행 위치를 유지합니다. 자막 길이를 늘린 구간에 새 단어 시간을 만들지는 않습니다. 문구의 글자를 바꾸면 기존 단어 시간이 해제되며 실행 취소로 함께 복원됩니다. 시간만 고치는 작업은 자막 스타일을 켜거나 바꾸지 않습니다.

자막 목록에서 문구를 바로 고칠 수 있습니다. SRT/VTT를 가져오거나 SRT로 저장할 수 있습니다. SRT에는 문구와 자막 시작·끝만 저장됩니다. 단어 시간·강조·스타일·애니메이션은 .sluproj 프로젝트에 저장합니다.

자막 글꼴은 Noto Sans KR과 Gmarket Sans 두 종류입니다. Noto Sans KR은 기본 자막에, Gmarket Sans는 제목이나 강조 자막에 사용할 수 있습니다. Gmarket Sans의 굵기는 500·700 중에서 선택합니다. 글꼴 파일은 앱에 포함됩니다.

오디오

클립 볼륨은 0–800%입니다. 페이드, 트랙 음소거·단독 재생, 영상의 오디오 분리를 지원합니다. 높은 게인은 리미터 동작과 왜곡을 유발할 수 있습니다. 미리보기는 Web Audio, 출력은 별도 믹서와 FFmpeg 리미터를 사용하므로 최종 출력도 들어보세요.

미리보기와 출력

미리보기는 WebGL2로 합성합니다. WebGL을 사용할 수 없으면 기능이 제한된 대체 렌더러가 동작합니다. 재생이 느리면 미리보기 해상도를 낮추거나 프록시를 생성하세요.

형식내용
MP4H.264, HEVC, AV1. 일반 호환성은 H.264가 가장 넓습니다.
WebMVP9 영상과 Opus 오디오
GIF오디오 없는 애니메이션

자동 인코더는 실행 검사를 통과한 GPU 인코더를 우선 사용합니다. 미리보기 합성·음성 인식·출력 인코딩은 서로 다른 GPU 작업입니다. 밀어내기·줌 전환 출력은 지원되는 GPU로 계산하며, 디졸브·와이프와 일반 합성은 CPU 경로를 사용합니다. 내보내기의 전환 처리 → CPU로 전환 가속만 끌 수 있으며 인코더 선택과는 별개입니다. GPU 전환을 사용할 수 없거나 처리에 실패하면 CPU로 재시도합니다. 출력의 모든 효과가 GPU로 처리되는 것은 아닙니다.

긴 프로젝트는 필요한 구간의 클립만 디코딩하고 하나의 인코더로 출력합니다. 완료 후 최종 파일명으로 바꿉니다. 원본과 같은 경로에는 출력할 수 없습니다. 내보내기는 한 번에 하나씩 실행합니다.

저장과 복구

Ctrl+S로 .sluproj를 저장합니다. 일반 저장은 편집 정보와 미디어 경로를 기록하고 추적 결과를 프로젝트 옆의 자료 폴더로 복사합니다. 영상·오디오·이미지도 함께 보관하려면 프로젝트 → 프로젝트 모아 저장을 사용하세요. 필요한 원본·보정·역재생·배경 제거·화질 향상 영상·정지 프레임·추적 결과를 복사한 별도 프로젝트를 만듭니다. 완성된 .sluproj와 그 옆 자료 폴더를 함께 옮기세요. 작업 패널에서 복사를 취소할 수 있습니다. 모아 저장한 프로젝트를 열면 FFV1 투명 영상의 필수 미리보기를 다시 준비하므로 시간이 걸릴 수 있습니다.

옮겨진 프로젝트는 함께 보관한 파일을 먼저 찾고 내용을 확인합니다. 누락된 미디어는 열 때 직접 연결할 수 있습니다. 추적 결과가 빠졌거나 손상되면 연결된 텍스트·이미지의 객체 추적 → 추적 파일 다시 연결에서 원래 .slutrack 파일의 백업을 선택하세요. 저장 당시와 같은 추적 파일인지, 연결된 영상이 분석 당시 영상인지 확인한 뒤 복구합니다. 원본이 아직 없으면 추적 파일부터 복구하고 나중에 원본을 연결할 수 있습니다. 같은 이름의 다른 파일은 사용할 수 없습니다. 원본 영상이 실제로 바뀌었거나 확인 정보가 없는 오래된 추적 결과는 원본을 복원하거나 다시 분석하세요.

1.12는 프로젝트 형식 10으로 저장합니다. 형식 1–9를 열 수 있으며, 새로 저장한 파일을 열려면 형식 10을 지원하는 앱이 필요합니다. 이전 앱에서도 작업할 파일은 먼저 다른 이름으로 저장해 원본 프로젝트를 보관하세요.

자동 저장은 프로젝트별로 최신 상태를 보관합니다. 프로젝트 메뉴의 복구 기록에서 선택할 수 있으며 수동 저장과 함께 사용하세요. 프로젝트 파일은 50 MiB까지 저장·열 수 있습니다.

캐시·모델·복구 파일과 media-derived의 보정·역재생·배경 제거·화질 향상 영상·정지 프레임, tracking-derived의 추적 결과는 사용자 데이터 폴더에 있습니다. 설정 화면에서 경로를 확인할 수 있습니다. 포터블도 이 폴더를 사용합니다. 추적 파일이 없는 상태의 일반 저장은 기존 연결 정보를 남기고 경고합니다. 프로젝트 모아 저장은 필요한 파일을 모두 찾은 뒤 실행하세요.

같은 경로의 원본 파일을 교체했다면 미디어를 다시 가져오거나 프로젝트를 다시 여세요. 이전 프록시·썸네일과 화면을 갱신합니다. 원본이 짧아져 사용할 수 없어진 전환은 해제하고 알립니다. 원본 파일의 교체는 실행 취소로 되돌릴 수 없으며, 이후 타임라인 실행 취소도 갱신된 원본을 사용합니다. 원본이 처리 도중 바뀌면 해당 출력·분석을 적용하지 않습니다.

현재 제한

광학 흐름·멀티캠·중첩 시퀀스·HDR 컬러 관리·협업·템플릿 마켓은 구현되지 않았습니다. 인물 배경 제거의 입력 범위와 윤곽 보완 제한은 해당 항목을 확인하세요. 출력은 8비트 SDR이며 HDR 톤 매핑은 없습니다. 새 자막 스타일은 미리보기·출력에서 같은 글꼴과 배치 코드를 사용하며 출력 프레임 시각에 맞춰 강조합니다. 기존 기본 텍스트는 Canvas/ASS 표현 차이가 있으며 ASS의 시작·끝은 1/100초 단위입니다. 블러 등 일부 영상 효과도 미리보기와 출력에 차이가 있을 수 있습니다. 타임라인에서는 여러 오디오 스트림 중 첫 스트림을 사용합니다.

출력은 동시에 겹치는 영상·이미지 32개, 오디오 소스 32개까지입니다. 미리보기는 기본 영상·이미지·오디오 후보를 합해 32개까지 처리하며 텍스트는 별도입니다. EQ를 유지한 채 분할된 영상에는 연속 소리 재생용 보조 디코더가 최대 32개 추가될 수 있습니다. 새 자막과 기본 텍스트가 여러 겹 교차하면 출력용 자막 프레임 버퍼가 최대 256 MiB로 제한됩니다. 초과하면 일부 스타일을 통일하거나 해상도를 줄여야 합니다. 단어 정보는 자막당 2,048개·프로젝트당 200,000개까지입니다. 10,000개 클립의 타임라인 탐색을 검사했지만 수 시간 분량의 복잡한 출력은 검증하지 않았습니다. 배속 클립의 분할 지점에서는 오디오 처리 결과에 작은 차이가 생길 수 있습니다.

Windows 코드 서명이 없습니다. 설치형 파일의 실제 설치 절차와 다른 PC의 호환성은 별도 검증이 필요합니다. 측정 조건과 결과는 검증 기록에 있습니다.

아주 짧은 간격으로 0.1배와 16배를 반복하는 속도 커브에서는 음정이 흔들릴 수 있습니다. 오디오 품질이 중요하면 제어점 간격을 넓히고 속도 차이를 줄이세요. 자세한 측정 조건은 검증 기록에 있습니다.
