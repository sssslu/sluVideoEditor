# AI·Computer Use로 편집하기

SLU Studio 1.18.0 기준입니다. 화면을 조작하는 외부 AI 도구에 이 문서와 편집 지시를 함께 전달하세요. 앱의 버튼·입력란·단축키와 Windows 파일 대화상자로 작업하는 안내입니다.

## 실행과 작업 경로

설치형의 기본 실행 파일은 `%LOCALAPPDATA%\Programs\SLU Studio\SLU Studio.exe`입니다. 설치 위치를 바꿨다면 실제 바로가기의 대상 경로를 사용하세요. 포터블은 내려받은 `SLU-Studio-1.18.0-Windows-x64.exe`를 실행합니다. 소스에서 배포 빌드를 마쳤다면 저장소 안의 `release\win-unpacked\SLU Studio.exe`가 실행 파일입니다. 앱 상단에서 버전을 확인할 수 있습니다.

AI에 원본 파일, 저장할 `.sluproj`, 출력 영상의 **절대 경로**를 알려주세요. 원하는 구간·자막·해상도·프레임 속도도 지정하면 편집 결과를 확인하기 쉽습니다. 프로젝트와 출력 영상은 서로 다른 파일입니다.

## 가져오기부터 출력까지

1. **가져오기** 또는 `Ctrl+I`를 누릅니다. Windows 열기 창의 **파일 이름**에 원본의 절대 경로를 넣고 **열기**를 누릅니다. 보관함에 파일 이름이 나타날 때까지 기다립니다.
2. 미디어를 선택하면 **소스** 모니터가 열립니다. **소스 시작점**, **소스 끝점**에 초 단위 숫자를 입력하거나 재생 위치에서 `I`·`O`를 누릅니다. **끝에 추가**로 대상 트랙 끝에 넣습니다. **삽입**은 현재 위치에 넣고 같은 트랙의 뒤 클립을 밀어냅니다.
3. **프로그램** 모니터로 돌아가 클립을 선택합니다. 정확한 위치로 가려면 **현재 시간**에 `HH:MM:SS:FF`를 입력하고 `Enter`를 누릅니다. 예를 들어 30fps의 `00:00:02:15`는 2초 15프레임입니다. 120fps에서는 프레임을 세 자리로 씁니다. `Esc`는 입력을 취소하고, 확정하지 않고 다른 곳을 누르면 이전 위치를 유지합니다. 잘못된 형식이나 프로젝트 범위 밖의 값은 이동하지 않고 오류를 표시합니다.
4. 시간 이동 후 `Ctrl+B`로 선택 클립을 분할합니다. `Delete`로 선택 클립을 삭제하고 `Ctrl+Z`로 실행 취소합니다. 속성 패널의 **시간 → 시작·길이·원본 시작점**은 초 단위 숫자로 편집할 수 있습니다. **시작**은 타임라인 위치, **원본 시작점**은 원본에서 사용할 위치입니다.
5. 자막은 **텍스트 → 자막 스타일 → 삽입**으로 넣고 속성 패널의 **텍스트 내용**을 고칩니다. **시간 → 시작·길이**로 표시 구간을 정합니다. 포함된 Noto Sans KR·Gmarket Sans를 바로 사용할 수 있습니다. 리틱체는 [설치 안내](사용설명서.html#reatic-font)에 따라 별도로 설치해야 하며, 필요한 글꼴이 없으면 해당 자막의 출력이 차단됩니다.
6. `Ctrl+Shift+S`로 **다른 이름으로 저장**합니다. Windows 저장 창의 **파일 이름**에 저장할 `.sluproj`의 절대 경로를 넣고 **저장**을 누릅니다. 이후 `Ctrl+S`로 갱신합니다. 원본 미디어도 함께 보관하세요. 자료까지 옮기려면 **프로젝트 → 프로젝트 모아 저장**을 사용합니다.
7. `Ctrl+E` 또는 **내보내기**를 누릅니다. **파일 형식**, **비디오 코덱**, **출력 해상도**, **프레임 속도**, **인코더**를 확인합니다. 기본은 MOV·H.264·PCM 오디오이며, MP4는 FLAC 오디오를 사용합니다. **내보내기 시작**을 누른 뒤 Windows 저장 창에서 출력 절대 경로를 지정합니다.
8. 작업 패널의 완료 상태와 **내보낸 파일 경로**를 확인합니다. 실패하면 표시된 이유를 읽고 수정한 뒤 다시 출력합니다. 완성 파일을 재생해 길이·화면·자막·소리를 확인하고 프로젝트도 저장합니다.

## 화면 밖의 클립 찾기

타임라인 툴바의 **클립 찾기**를 누릅니다. 타임라인에 포커스가 있을 때는 `Ctrl+F`도 가능합니다. **클립, 자막, 트랙 또는 시작 시간 검색**에 검색어를 입력하고 **클립 검색 결과**에서 트랙 번호·이름·시작 시간을 확인하세요. `↑`·`↓`로 결과를 이동하고 `Enter`로 선택하면 그 클립과 트랙으로 이동합니다. 기존 선택에 더하려면 `Shift+Enter` 또는 `Shift+클릭`을 사용하세요. `Esc`로 닫습니다.

이름·자막·트랙명은 부분 검색합니다. `트랙 2`는 화면의 트랙 번호이며, 시작 시간은 표시된 `HH:MM:SS:FF` 전체나 `90초`처럼 입력합니다. 숨기거나 잠근 트랙도 검색됩니다. 같은 이름의 클립은 트랙과 시작 시간으로 구분하세요.

## 반복 편집 줄이기

- **색 보정을 복사하려면** 기준 영상·이미지 하나를 선택하고 **색상 → 색 보정 복사**를 누릅니다. 대상 클립을 선택해 **색 보정 붙여넣기**를 누릅니다. 밝기·대비·채도·블러·프리셋·HSL·곡선·LUT를 함께 적용하며 잠긴 트랙은 제외합니다.
- **자막을 한꺼번에 고치려면** **자막 → 찾아 바꾸기**에서 **찾을 자막 내용**, **바꿀 자막 내용**을 입력하고 **전체 바꾸기**를 누릅니다. 전체 자막에서 대소문자를 구분해 일반 문자열을 바꿉니다. 빈 대체 문구는 해당 문자열을 지웁니다. 잠긴 트랙은 제외하며 바뀐 자막의 단어 시간은 초기화됩니다. 한 번의 `Ctrl+Z`로 되돌릴 수 있습니다.
- **컷 사이의 음량을 맞추려면** 소리 있는 클립들을 선택하고 **오디오 → 선택 클립 음량 맞추기**를 실행합니다. 클립별로 −16 LUFS를 목표로 조절하고 −1 dBTP·볼륨 800% 한도를 지킵니다. 한도에 걸리면 목표보다 작을 수 있습니다. 잠김·음소거·무음·분석하기 너무 짧은 클립은 건너뜁니다. 분석이 끝나면 선택한 클립에 일괄 적용합니다. 한 번의 `Ctrl+Z`로 되돌릴 수 있습니다.

## 조작할 때 확인할 점

- 화면 크기와 패널 너비가 달라질 수 있으므로 이름과 역할을 함께 확인하세요. 예를 들어 **속성 패널 → 오디오 → 게인**에서는 **게인** 슬라이더를 조작합니다. 입력 직후 속성 값·선택 클립·재생 위치를 다시 읽으세요.
- 텍스트·숫자 입력란에서는 편집 단축키가 적용되지 않을 수 있습니다. 입력을 마친 뒤 타임라인이나 프로그램 모니터에 포커스를 옮깁니다. **현재 시간**은 `Enter`로 확정하면 프로그램 모니터로 포커스가 돌아가 바로 분할할 수 있습니다.
- 원본 구간은 소스에서, 배치·분할 위치는 프로그램에서 정합니다. 29.97 같은 소수 프레임 속도의 시간코드는 논드롭 프레임 번호를 사용합니다.
- 파일 가져오기·분석·출력은 완료 상태를 보고 다음 단계로 넘어갑니다. 숫자만 바뀌었거나 대화상자가 닫혔다는 이유로 저장·출력이 완료됐다고 판단하지 않습니다.

## 지시 예시

경로와 수치를 실제 작업에 맞게 바꿔 전달하세요.

> SLU Studio에서 `D:\영상\원본.mp4`를 열어 원본 2초부터 12초까지 사용해 줘. 1920×1080, 30fps로 만들고, 타임라인 0초부터 3초까지 “오늘의 기록”을 간결한 자막으로 넣어 줘. 프로젝트는 `D:\영상\결과.sluproj`, 출력은 `D:\영상\결과.mov`로 저장해 줘. 출력 완료 후 파일을 재생해 길이와 자막을 확인해 줘.
