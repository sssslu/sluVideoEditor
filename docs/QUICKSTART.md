# SLU Studio 빠른 시작

Windows x64용 1.13.0 기준입니다. 전체 기능 설명은 파일을 내려받아 브라우저에서 열거나 앱 왼쪽의 **도움말**에서 확인하세요. [전체 사용설명서 다운로드](https://github.com/sssslu/sluVideoEditor/releases/download/v1.13.0/SLU-Studio-1.13.0-guide.html)

## 다운로드와 실행

- [설치형 EXE](https://github.com/sssslu/sluVideoEditor/releases/download/v1.13.0/SLU-Studio-Setup-1.13.0-x64.exe)를 실행해 설치합니다.
- [포터블 EXE](https://github.com/sssslu/sluVideoEditor/releases/download/v1.13.0/SLU-Studio-1.13.0-Windows-x64.exe)는 내려받은 파일을 실행합니다. 실행 중 내부 파일을 푸는 시간이 필요합니다.
- 이후 버전은 [최신 릴리스](https://github.com/sssslu/sluVideoEditor/releases/latest)에서 확인할 수 있습니다.

앱 상단 왼쪽에 실행 버전이 표시됩니다. Windows 코드 서명은 없으며, 대화식 설치 절차와 다른 PC 호환성은 아직 검증하지 않았습니다. 내려받은 파일의 SHA256은 릴리스의 해시 목록과 대조할 수 있습니다. [파일 해시](https://github.com/sssslu/sluVideoEditor/releases/download/v1.13.0/SHA256SUMS-1.13.0.txt)

## 첫 영상을 타임라인에 넣기

1. **가져오기**를 누르거나 탐색기의 영상·오디오·이미지 파일을 앱으로 드래그합니다.
2. 보관함에서 미디어를 선택해 소스 모니터에서 확인합니다.
3. 일부 구간만 쓸 때는 시작 위치에서 `I`, 끝 위치에서 `O`를 누릅니다.
4. **끝에 추가**를 누르면 대상 트랙 끝에 들어갑니다. **삽입**은 현재 위치에 넣고 같은 트랙의 뒤 클립을 밀어냅니다.
5. 프로그램 모니터에서 `Space`로 재생하거나 멈춥니다.

미리보기가 느리거나 코덱 때문에 화면이 나오지 않으면 해당 미디어의 프록시를 생성하세요. 프로그램 모니터의 미리보기 해상도도 낮출 수 있습니다.

## 자르고 순서 바꾸기

- 클립을 드래그해 이동하고, 양 끝을 드래그해 사용할 길이를 조절합니다.
- 재생헤드를 옮긴 뒤 `S`를 누르면 선택한 클립을 분할합니다. `Delete`로 선택한 클립을 삭제합니다.
- `Ctrl+Z`로 실행 취소하고 `Ctrl+Shift+Z`로 다시 실행합니다.
- `Shift`+클릭으로 여러 클립을 선택합니다. `Ctrl`+마우스 휠로 타임라인을 확대합니다.
- 트랙은 필요할 때 생깁니다. 이미 클립이 있는 자리에 놓으면 위에 새 트랙이 생기고, 클립을 모든 트랙 위로 끌면 맨 위 트랙이 됩니다. 위 트랙이 아래 트랙을 덮습니다.
- 트랙의 잠금·숨김·음소거 버튼을 사용합니다. 영상 트랙의 숨김은 오디오를 끄지 않으므로 소리는 음소거로 조절합니다.

속성 패널에서 위치·크기·색상·속도·오디오를 조절합니다. 속도는 퍼센트(10–50000%)로 입력하고, 여러 클립을 선택하면 한 번에 바꿉니다. 선택한 클립은 오른쪽 클릭 메뉴나 <kbd>Alt</kbd>+<kbd>G</kbd>로 렌더링해 하나로 합칠 수 있습니다. 분할은 <kbd>Ctrl</kbd>+<kbd>B</kbd>이며 단축키는 CapCut 배치를 따릅니다. 키프레임 그래프에서 시간에 따른 값을 편집할 수 있습니다.

## 자막 넣기

직접 문구를 넣으려면 **텍스트 → 텍스트 추가**를 누르고 속성 패널에서 내용을 입력합니다. **자막 스타일**의 삽입 버튼으로 외곽선 강조·줄 배경·간결한 자막도 넣을 수 있습니다.

자막 글꼴은 **Noto Sans KR**과 **Gmarket Sans** 두 종류입니다. 앱에 포함되어 있으며 Gmarket Sans는 굵기 500·700을 지원합니다. 글자색·강조색·외곽선·배경·정렬과 등장·퇴장 효과를 조절할 수 있습니다.

음성을 자동으로 인식하려면 다음 순서로 진행합니다.

1. 음성이 있는 영상이나 오디오 클립을 선택하고 **자동 자막**을 엽니다.
2. Base·Small·Large-v3-turbo Q5 중 모델을 설치합니다. NVIDIA GPU 인식을 사용하려면 별도의 CUDA 음성 엔진도 설치합니다.
3. 언어와 자막 길이를 정해 인식합니다.
4. 생성된 문구와 시간을 확인하고 수정합니다. 배경음악·겹친 목소리·무음에서는 오인식이 생길 수 있습니다.

모델 설치 후 음성 인식은 PC에서 실행됩니다. SRT/VTT를 가져올 수도 있습니다. 문구·시간은 SRT로 내보낼 수 있고, 글꼴·효과·단어 강조는 프로젝트 파일에 저장됩니다.

## 프로젝트 저장과 이동

`Ctrl+S`를 눌러 `.sluproj` 파일을 저장합니다. 일반 저장은 편집 정보와 미디어 경로를 기록하므로 원본 영상도 함께 보관하세요.

다른 폴더나 PC로 옮길 때는 **프로젝트 → 프로젝트 모아 저장**을 사용합니다. 완성된 `.sluproj`와 그 옆 자료 폴더를 함께 옮기세요. 배경 제거·흔들림 보정·역재생·AI 화질 향상으로 만든 영상도 복사 대상입니다.

1.13은 **프로젝트 형식 10**으로 저장하며 형식 1–9를 열 수 있습니다. 새로 저장한 파일은 형식 10을 지원하는 앱에서 열어야 합니다. 이전 파일을 보관하려면 **다른 이름으로 저장**을 사용하세요. 자동 저장 기록은 프로젝트 메뉴의 **복구 기록**에서 확인할 수 있습니다.

## 영상으로 내보내기

1. 오른쪽 위 **내보내기**를 누릅니다.
2. 기본값 **MOV · H.264**(무손실 PCM 오디오)를 그대로 쓰면 됩니다. 일부 휴대폰·메신저·사이트에서 열리지 않으면 **MP4**(무손실 FLAC 오디오)를 고르세요. 해상도와 프레임 속도를 정합니다.
3. 인코더를 **자동**으로 두면 실행 검사를 통과한 GPU 인코더를 우선 사용합니다. CPU도 직접 선택할 수 있습니다.
4. **내보내기 시작**을 누르고 저장 위치를 정합니다. 작업 패널에서 진행 상태를 확인하거나 취소할 수 있습니다.
5. 완성 파일을 재생해 화면·자막·소리를 확인합니다.

WebM, GIF, WAV 출력도 지원합니다. GIF에는 오디오가 없고 WAV는 타임라인 소리만 저장합니다. 출력은 8비트 SDR이며 HDR 톤 매핑을 지원하지 않습니다.

## AI 화질 향상

필요한 짧은 구간을 먼저 자른 뒤 **미디어 → AI 화질 향상**을 엽니다. 첫 사용 때 약 **10.3GB**의 엔진·모델을 내려받으며 설치에는 **30GiB 이상**의 여유 공간이 필요합니다. NVIDIA GPU와 CUDA 드라이버가 필요하고 메모리 여유가 부족하면 작업이 중단됩니다.

**2×·4×**를 선택하고 최대 2초 구간의 비교 결과를 확인한 뒤 클립에 적용합니다. 만들어진 세부나 질감이 원본과 달라지거나 프레임 사이에서 흔들릴 수 있으므로 움직이는 부분도 확인하세요.

1.11에서 RTX 4080 SUPER 16GB·RAM 32GB로 검사한 720p·1080p 표본은 **15프레임당 52.8–100.1초**가 걸렸습니다. 모델 확인·준비·처리·종료를 포함한 값이며, 완성 영상과 프록시 생성 시간은 별도입니다. 4K AI 출력과 장시간 영상의 성능은 검증하지 않았습니다.
